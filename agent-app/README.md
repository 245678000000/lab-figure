# AISI-figure

独立于 VS Code 的本地作图应用。界面采用白底、浅灰边框和蓝色按钮；主页面左右两个框：左侧编辑 R / Python 代码，右侧预览图片，底部对话修改。图型与列映射在顶部“作图设置”中。多面板排版由用户自行完成。

## 打开

双击桌面上的 **AISI-figure**，或仓库根目录的 `打开 AISI-figure.vbs`，现在默认打开独立桌面窗口，无浏览器地址栏和标签页。再次双击会切回已有窗口。

桌面版使用 Windows WebView2 和 pywebview，保留 AISI 图标及原有左右代码/图片布局。导入使用系统文件选择器，导出使用“保存文件”窗口。原有数据和图像历史共用 `workspace`；桌面窗口的界面偏好与代码草稿保存在 `workspace/desktop-profile`。浏览器中尚未运行的草稿仍留在原浏览器，不会自动迁移。

关闭桌面窗口后，本机计算服务保留，避免中断正在进行的作图任务。重启电脑后再次双击即可启动。桌面窗口报错时检查 `workspace/desktop.log`，服务日志在 `workspace/server.log`。

安装桌面依赖：`..\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt`。重建桌面入口：运行仓库中的 `setup/create_desktop_shortcut.ps1`。需要浏览器版时可运行 `..\.venv\Scripts\pythonw.exe launch.py --browser`。

也可以在 `agent-app` 目录运行：

```powershell
..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8765
```

## 作图风格

原有九种图继续直接使用 labstyle 模板。新增图型通过 `figure-style.R` 继承其风格：基础字号 12 pt、原主题的轴字和图例比例、深蓝/暗红及类别色板、无网格开放坐标轴、原小字标注、300 dpi 导出。参考技能为 `skill/lab-figure/SKILL.md` 和 `references/style-spec.md`，不是只支持九种图。

新图型按相近图族选用原尺寸预设，热图和长类别图参考原相关热图按标签与行列数增加画布，保留字号，不通过缩小文字硬塞。样式设置集中在 `figure-style.R`，随版本快照与复现包保存；`figure-style.json` 记录实际字号、尺寸与风格来源。单独下载代码还需复现包内的样式辅助文件及 plot-settings.json，建议下载全部。新样式用于新生成的图，历史结果和手动代码版本保留。

默认画布现按图型设置比例：散点图/火山图采用 4.6 × 4.6 英寸；PCA/嵌入图接近方形；箱线、柱图及配对差值图按类别数加宽；热图、富集、森林图继续按行列与标签安排尺寸。保留原字号和统计方法；用户明确选择的单栏、宽图或毫米尺寸优先。生成代码中的 `wh` 就是宽高，仍可直接编辑。旧图保留原比例，新生成才使用新默认尺寸。

## 作图

支持 CSV、TSV、XLSX 上传，工作表与表头选择、列映射、缺失值预览。每个图型都提供人工合成示例。

共有 30 个单图入口（包括受约束的自定义图层）：

- 基础与临床：ROC、箱线、小提琴、KM、Cox 森林、应答率柱图、AUC 对比、相关热图、构成饼图。
- 差异与富集：火山、MA、富集气泡、富集条形、GSEA 运行分数曲线。
- 表达与单细胞：表达热图、已有 UMAP / t-SNE 坐标、Feature、Marker dot、细胞组成、配体受体气泡。
- 统计与质量检查：配对连线、配对差值、相关散点、PCA、样本距离、缺失值、UpSet、网络、直方、自定义图层。

R 支持所有入口，Python 支持 ROC、箱线、应答率三个模板。自定义入口支持散点、折线、柱状、箱线、小提琴的声明式参数，不接受模型提交任意代码。

UMAP / t-SNE、差异分析、富集及细胞通讯等预计算结果须由用户提供；画图不会冒充完成其上游分析。PCA、配对差值、相关系数等入口会计算并保存实际结果。火山图保留全部点，阈值与标注数可设置；矩阵支持不缩放、按行或按列 Z-score。

每次生成保留 PDF / PNG / SVG、实际分析数据、统计表、代码、样本选择记录、输入哈希、运行日志、环境版本及 ZIP 复现包。PDF 字号与碰撞检查不通过时显示警示，最终使用前仍须看图核查。

## 跨图配色、毫米尺寸与结果表识别

“作图设置 → 更多设置”中可启用跨图固定分组颜色，并打开“管理分组配色”。分组名称按原值精确匹配；同名分组在不同数据和图型中保持同色，初始色板来自原 labstyle 配色。配色保存在本机 `workspace/preferences/group-colors.json`，可用颜色选择器修改，新生成的图生效。适用于按分组着色的箱线、小提琴、比例、KM、饼图、嵌入、组成、散点、PCA、配对与自定义图；连续表达梯度、火山图的上下调语义配色保持各自规则。每张图的 `plot-settings.json` 保存当次颜色，历史与手动代码重跑使用该快照。

尺寸选择“自定义毫米”后填写宽度，或同时填写宽、高。高度留空时保留所选模板的原比例。调整实际导出的 PDF / PNG / SVG，不缩小字体；检查页会报告最终 PDF 的尺寸、字号和碰撞。R PDF 设备会按整点取整，尺寸核查容许 0.36 mm 差异，实际尺寸会明确记录。

上传表格后，数据页显示按列结构识别的 DESeq2、Seurat marker / DotPlot、已有 UMAP / t-SNE 坐标及 clusterProfiler 富集结果。点击“应用列映射”后核对图型、变量和参数再生成。多个 cluster / 比较需先明确选择一个，筛选在本次计算前执行并记录，原始数据不变。未声明对数底的 avg_logFC 不会直接当作 log2FC；pct.1 不会自动当百分比；原始 P 值不会替代校正 P 值；只有 NES 的 GSEA 汇总不会冒充 running ES 曲线。识别表结构不能验证文件来源或上游分析是否正确。

参考列定义：[DESeq2](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)、[Seurat](https://satijalab.org/seurat/reference/findallmarkers)、[enrichplot](https://github.com/YuLab-SMU/enrichplot/blob/master/R/dotplot.R)。

## 编辑代码与更新图片

先上传数据或试用示例生成图像。左侧可直接编辑完整代码，点击“运行并更新图片”（或 Ctrl+Enter）后，在本机执行并刷新右侧图像。请保留 source_data.csv 输入及 PDF / PNG / SVG 导出语句。编辑框支持行号、R / Python 语法高亮、括号匹配、Tab 缩进和撤销重做。点击“查找”或按 Ctrl+F / Ctrl+H 展开查找替换，可逐处或全部替换，支持区分大小写。运行错误会显示中文原因；能确定行号时可直接跳转，R 运行错误可能仅定位到表达式开始位置，会标记“附近”。

右侧支持放大、缩小、100% 原始像素、适应窗口及全屏查看；放大后可按住图片拖动，也可用滚动条查看。图片区域支持 Ctrl+滚轮缩放，键盘 + / - 缩放、0 适应窗口。中间分隔线可拖动调整两框宽度，双击恢复均分；聚焦分隔线后可用左右箭头调整、Home 恢复均分。缩放仅影响预览，不改变导出图像。

每次成功运行创建新版本，保留来源代码、输入快照及统计输出，历史菜单可恢复任一成功版本。“恢复本版代码”只恢复当前版本的原始代码，历史版本不会删除。未运行的草稿按版本保存在当前浏览器；运行报错会显示错误，并保留草稿和上一张成功图片。输入快照已执行来源版本的排除规则；代码内新增筛选需核对实际统计，不从模板参数反向推断手改代码。

模板状态下，对话继续更新模板代码和图片。存在手动代码或未运行草稿时，对话交给模型修改当前完整脚本，先显示修改前后代码差异，接受后写入编辑框并高亮新增行；放弃会保留原草稿。接受修改可通过 Ctrl+Z 撤销。用户点击运行后更新图片。未连接模型仍可手动编辑运行。模型修改后的脚本不会自动执行。手动代码运行使用本机用户权限及 120 秒超时，不是隔离沙箱；请只运行自己确认的代码。

## 模型连接

无需模型也能通过界面参数作图，或使用“改成宽图”“标题改为…”等固定指令。自由对话需要在“模型设置”启用连接。

| 平台 | 账号模式 | API 模式 |
| --- | --- | --- |
| ChatGPT / OpenAI | 本机 Codex 官方客户端 | OpenAI Responses 或兼容接口 |
| Claude | Claude Code 官方客户端 | Anthropic Messages |
| Kimi | Kimi Code 官方授权 | Kimi / Moonshot 兼容接口 |
| DeepSeek | 当前无接入入口 | 开放平台 API Key |
| GLM / 智谱 | 当前无接入入口 | 开放平台或 Coding Plan 对应密钥与地址 |
| 千问 / Qwen | 当前无接入入口 | 百炼、工作空间或订阅对应密钥与地址 |
| 其他兼容服务 | — | 自填地址、模型和协议 |

账号模式复用官方客户端授权，登录操作在官方页面由用户完成，具体可用性取决于账号权限。普通聊天网站账号不能直接当作 API 凭证。Qwen Code 的旧 Qwen OAuth 已停止提供。各平台地址可编辑，以所用地区、订阅及工作空间的官方配置为准。

账号模型可留空使用客户端默认值，API 模式须填写模型 ID。平台、地址、模型、协议与连接方式保存在 workspace/preferences/model-settings.json，重启后恢复。API 密钥仅保存在本次服务进程内存中；重启后保留平台配置但停用 API 连接，需重新填密钥并启用。账号模式保留启用选择，实际授权有效性由官方客户端决定。账号凭证由官方客户端管理，应用不读取其密钥文件。停用连接不会替用户注销官方客户端账号。

模板模式中模型选择经过校验的作图参数，本地服务执行模板脚本；代码编辑模式中模型仅提交代码草稿，由用户点击运行。发送给模型的是需求、列结构、类别摘要和计算结果，原始表格不整体上传；统计摘要会限量。代码修改对话也会发送当前编辑框中的完整代码。账号桥接会关闭作图规划进程的工具能力。

官方说明：[Codex 认证](https://learn.chatgpt.com/docs/auth)、[Claude Code 认证](https://code.claude.com/docs/en/authentication)、[Kimi Code](https://moonshotai.github.io/kimi-code/en/guides/getting-started)、[DeepSeek](https://api-docs.deepseek.com/)、[智谱](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[百炼地址](https://help.aliyun.com/en/model-studio/base-url)。

## 分析约束

阳性/事件类别与配对参考条件须明确选择。按所用变量处理缺失数据，并记录移除数量；原始上传字节和历史结果保留。缺失值图保留缺失数据，配对入口拒绝不完整或重复配对。

ex vivo 模式读取上一级项目的 `analysis_config/exvivo_sample_exclusions.tsv`，先排除已确认的 HNSCC3_HD / HNSCC3_tumor 及其别名，忽略大小写，保留 HNSCC3_LD，再进行本次计算。相关散点分别计算 SCC 与 PCC。预计算结果入口不能代替排除后的上游重算，会阻止将其作为本次 ex vivo 重分析。应用没有实现全基因排名、中心化或 CPM / TPM 转换；不得将不同输入版本混写为彼此修正版。

## 看图修改、版本对比与任务停止

图片区的“看图修改”把当前成功版本 PNG、当前编辑代码、当次尺寸/配色和样式辅助文件发给所选模型。模型可检查遮挡、布局等实际可见问题，并提出代码草稿；它不能把尚未运行的草稿当作已渲染效果。看图结论是辅助意见，不代替本地统计与最终人工检查。

- ChatGPT / Codex 账号通过官方 CLI 的 `--image` 传入图片，已用合成数据完成真实请求与界面验收。
- API 支持 Responses、OpenAI 兼容 Chat Completions、Anthropic Messages 的图像内容块；须选择服务商支持图片输入的模型。接口格式已自动测试，未提供凭证的服务没有声称完成真实调用。
- Claude 和 Kimi 当前账号桥接仍支持文字规划/代码修改；其看图入口会明确提示使用支持图像的 API 或 ChatGPT / Codex 账号，不会默默忽略图片。
- 图片只在用户点击发送看图请求时传给模型；原始数据文件不整体上传，图上已有标签/数值和当前代码会随请求发送。最大 PNG 15 MB。

“AI 修改对比”只列出变更段落，包含前后行号，接受后才写入编辑器；未接受的建议在当前浏览器会话中保留。若用户在收到建议后继续修改了代码，应用会阻止旧建议覆盖新草稿。成功运行后可在右侧“查看修改前 / 返回当前图片”间切换，下载始终对应当前版本。

运行中显示阶段与已用时间，点击“停止”会取消等待中的 HTTP 请求，或终止本次任务启动的 CLI / R / Python 进程树；停止后保留原图、草稿及历史版本。取消网络等待不保证服务商撤回已经开始的远端计算。刷新页面后可以继续查看当前运行任务。

图像 API 格式参考：[OpenAI 图片输入](https://developers.openai.com/api/docs/guides/images-vision)。

## PCA 方向与转置副本

PCA 生成前必须确认“行是样本，数值列是特征”。方向声明随参数保存，模型不能自行替用户勾选。基因在行的矩阵可在数据页或 PCA 设置中打开“矩阵转置预览”，选择基因标识列和样本数值列，核对前 5 行、前 7 列预览后再保存。

转置只改变所选矩阵的方向，不补值、不标准化、不合并重复基因；重复/缺失标识、非数值样本列或无穷值会被拒绝。表格支持 100 MB、100,000 行、50,001 列及 10,000,000 单元格（各项同时满足）；CSV/TSV 在读入超限数据前停止，XLSX 先检查工作表尺寸。可将至多 50,000 个基因转置为特征列。转置后需核对分组与数值变换，应用不会从样本名猜测分组。

新副本记录原数据 ID、SHA-256、标识列及样本列；原始文件保留。后续 PCA 的输入记录和复现包包含这份来源信息。ex vivo 排除在转置后的样本选择阶段执行，再进行缩放和计算，保留 HNSCC3_LD。


### 大矩阵与结果一致性

- PCA 支持明确选择“全部数值特征”，排除所选样本标识、着色分组列；请先移除其他数值注释列，或改为手选特征。不会自动选高变基因、补值、做 log 转换。仍使用精确 `prcomp`，样本数与特征数中较小的一项不能超过 1,000；不支持直接导入稀疏单细胞对象。
- 页面预览前 12 行、24 列，概览最多 100 列；列搜索每次显示最多 100 个匹配项，保留搜索范围外的已选特征。传给模型的列摘要最多 200 列，大量手选特征由本机完整保留；如需改变集合，请在参数中修改。
- 大量手选特征配置保存为 `analysis-settings.json`，与脚本、原始选择快照一起进入 ZIP，手动代码版本继续使用同一配置。全部数值特征模式代码保持简短。
- PCA 下载包含 `pca_coordinates.csv` 与 `pca_loadings.csv`；历史 ZIP 在下载时补入已存在的结果文件，不重算历史图。
- 查看修改前图片时点击“看图修改”，先返回当前编辑版本；恢复后台任务和历史版本时同步其来源数据。
- 自动回归使用 20,000 基因 × 8 样本的合成矩阵，验证转置数值、PCA 解释方差与独立 SVD 一致、完整载荷输出及代码重跑。

宽表 R 脚本使用随包保存的 `wide-table.R` 和 `source-schema.json` 读取同一个 CSV，校验列名、顺序、行数并保留输入类型，减少基础 `read.csv` 在数万列上的开销。PCA 特征名单在样本筛选前固定到 `analysis-settings.json`，防止排除样本后重新推断类型时把注释列混入分析。所有这些文件随手动版本复制并进入下载包。

本机合成 20,000 基因 × 8 样本测试中，绘图执行阶段约由 41 秒降至 1.4 秒；该时间不包含导入、转置及输入检查，也不代表其他尺寸数据的固定耗时。临时断线时任务编号会保留，刷新可恢复同一服务进程内已完成的任务；服务重启不保留内存任务，但成功图像仍可从历史版本打开。


## 样本信息、表达检查与批量统计

在“作图设置 → 分析设置”中依次使用三个入口。主工作区仍为左代码、右图片。

1. **连接样本信息表**：表达矩阵先整理为每行一个样本，上传注释 CSV/TSV/XLSX，指定两表样本 ID 并精确对齐。缺失/重复 ID 阻止连接，多余样本须明确允许。患者、分组、条件、批次等文本列会预选供核对，可手动调整；保留 001、01、NA 等标识，年龄和功能测量保持数值。预览后保存副本，两个原文件保留。
2. **表达单位与数据检查**：声明 counts、CPM、TPM、已取对数或未知单位，明确特征。已连接注释列不进入全部数值表达特征。报告缺失、无穷值、负值、零方差、低表达及数值范围。移除零方差、低表达筛选、log2(x+1) 均须明确选择。低表达规则按取对数前的输入判断：至少指定样本数的值严格大于阈值。保存副本，不插补、改写原矩阵或将 CPM/TPM 互换。取对数不等于测序深度标准化。
3. **批量相关 / 配对统计**：选择一个功能指标和基因集合，分别保存 SCC、PCC、有效 n、原始 P、独立 BH 校正 q 和无效原因。支持原始输入、分组内均值中心化、比较减参考的配对差值。中心化相关为探索性，未拟合重复测量模型。配对模式另输出 Wilcoxon signed-rank、均值/中位差值及 rank-biserial 效应量。先选择条件并处理明确允许丢弃的不完整配对，再检查参与统计的缺失值。按基因删除缺失观测仅在明确选择 pairwise 时启用。

ex vivo 清单排除在 QC、中心化、配对、排名及全部统计之前执行，保留 HNSCC3_LD。CPM/TPM 来源分开记录，不作混样归因。

结果可切换 SCC/PCC/配对表、搜索基因和分页；完整结果按原始 P 升序、特征名排序，不受页面行数限制。点击基因生成一张基于固定处理后输入的散点图；差值轴标为 Delta（差值）并显示比较方向，中心化轴也明确标注。完整检验族的 q 值保留在来源记录和图像检查页。已保存分析可从下拉列表恢复。

统计复现包包含完整结果、处理后的 analysis_input.csv、参数、原文件哈希及来源、软件版本，以及可用 Python 执行的 reproduce.py。该脚本从固定处理后输入重算统计；前序对齐/筛选/差值操作记录在 manifest，原文件仍保留在本机数据历史中。图像包另含 analysis-context.json，随代码手改版本保留。

“载入分析示例”提供人工合成的 40 基因、8 位供者、两条件 counts 与功能测量，不需要连接模型。当前不执行 DESeq2、富集或单细胞上游分析。

### 编辑标题、坐标名称和图注

生成或打开历史图片后，点击图片上方的“在图上编辑”。点击图中的主标题、横轴名称、纵轴名称或统计说明，工具栏会显示实际导出 PDF 中的字体、字号，并可选择字体、输入字号。横轴和纵轴字体可分别修改。标题和坐标文字可在选中后的文字框里修改；留空可隐藏。数值、数据列、坐标范围与统计方法不会因此改变。

最下面的相关系数/P 值属于统计说明，颜色或分组说明才是图例。统计说明直接拖动文字即可移动，多行会作为一组一起移动；方向键可微调，Shift + 方向键加速。支持散点图说明及 ROC、KM 等图中的单个统计文本块，保留原来的计算数值。未可靠识别的文字、基因标注和显著性括号仍使用代码修改。预览使用实际 PDF 的背景与文字位置；浏览器字体度量可能有细微差别，应用后查看最终导出。

“更多文字与图例设置”保留完整文字字段、刻度字号，以及图例的上下左右/隐藏/手动定位。图例的手动定位仍使用标记。字体支持 Arial、Times New Roman、Calibri、Cambria、Consolas、微软雅黑和宋体；系统缺少对应字体时可能回退。

应用使用当前代码编辑框和原版本的数据快照，保存为新版本，无需模型或 API。修改块写在导出语句之前；保留标准 `save_fig(p, ...)` / `save_fig(fig, ...)` 导出入口。PNG、PDF、SVG 同步更新，复现 ZIP 包含文字/位置设置和 R/Python 辅助脚本。历史图片与原始数据保持不变。

编辑面板中的“字体大小（pt）”可分别设置主标题、坐标名称、刻度、图例、统计说明，支持 5–48 pt。留空或点“恢复原字号”后应用，即恢复当前脚本原样式。字号写入导出代码并保存在版本中，尺寸调整不会自动把字体缩小；布局检查仍以最终 PDF 为准。

### 左侧栏与账号额度

左侧栏集中放置上传数据、作图设置、数据选择、可搜索历史，以及当前模型和账号。右侧保留代码/图片与对话输入。侧栏可收起；小窗口首次打开时默认收起，之后记住手动选择。

账号信息只读查询，不读取或展示官方客户端的 token 文件。ChatGPT/Codex 通过官方 `account/read`、`account/rateLimits/read` 返回邮箱、套餐和额度窗口；显示剩余百分比、重置时间，并优先使用多额度桶响应。未返回的数据显示未知，不当成零。启动、更新模型设置或手动点“刷新”时查询，展示最近更新时间；额度属于账号共享额度。查询本身不发起模型生成，也不兑换额度重置。

Claude Code 使用 `auth status` 返回的邮箱/套餐；当前桥接不提供其订阅额度。Kimi 当前桥接无法可靠查询身份与额度，因此提供官方入口并明确标注不可读取。GLM、千问和其他兼容 API 不虚构额度。API 模式显示服务域名和密钥的 SHA-256 短标识（非密钥内容），不能推断登录邮箱。DeepSeek 官方 API 地址可调用只读余额接口；自定义代理地址的凭证绝不会转发到 DeepSeek 官方站点。查询错误不回显原始响应或凭证。

接口依据：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Claude CLI](https://code.claude.com/docs/en/cli-reference)、[DeepSeek 余额查询](https://api-docs.deepseek.com/api/get-user-balance/)。
